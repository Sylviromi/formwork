# Changelog

## 1.1.0

### Added
- NuclearCraft multiblocks support.
- Mirror a placement from the placement card.
- Remembered variants: the editor reopens with the variants you last chose for each structure.
- Favourites in the browser.
- Building/Dismantling animation.
- JEI updates.
- "Reset to original" for variants.

### Changed
- The status box in the editor view only appears when the structure will not form.
